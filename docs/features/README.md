# docs/features — finished feature documentation

One doc per shipped feature, written **only after** the code is built, checked, and tested. Name: `<feature-slug>.md`.

Every doc contains:

- **What it does** — beginner-friendly English (the user may be new to the stack)
- **Flowchart** — a Mermaid ```` ```mermaid ```` diagram of how the feature works
- **How it works** — the key files and flow
- **How to test it** — commands or manual steps

Use **Myanmar (Burmese)** only when a concept is deep and hard to express simply in English.
